2000–2025 burning calendar

Color is log10(count + 1). Cyan outline: unusual month (|robust z| > 3.5 vs that calendar month’s 2000–2025 median). The dashed line is 2012, when VIIRS begins. Hover a cell for the count, z-score, and model interval. Back-cast years (2000–2011) carry model error.

Data: NASA FIRMS, MODIS Collection 6.1 (MCD14ML) and VIIRS S-NPP (VNP14IMG), firms.modaps.eosdis.nasa.gov. NASA data has no restriction on use; cite FIRMS.

This tool and model code: Apache-2.0. Unlisted demo build (static, precomputed from the local model run). Intervals are Mondrian conformalized quantile regression (90% target), summed over cells in the AOI, and are not a formal regional confidence interval.
